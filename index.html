Frequently asked questions.

Short answers for a client-only walkthrough.

Is this a real CAC portal?+

No. RegulAI is a client-only prototype that demonstrates the intended journey and screen states; it does not submit a real government application.

What does the document check do?+

It checks mock file format, size, legibility, completeness and extracted text. A flagged file must be re-uploaded before the demo can move to payment.

Does it perform biometric verification?+

No. The prototype makes no government-level biometric identity claim. It only demonstrates document-readiness feedback.

What happens after registration?+

The demo keeps the registration record connected to a starter company profile, brand direction and editable landing-page output.
